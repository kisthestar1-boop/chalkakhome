쿠팡 셀러 영업 메일 기본형

상세페이지가 아쉬운 쿠팡 셀러에게 — 먼저 무료로 만들어 주고, 그다음 찰칵상세로

진행 순서

  1. 쿠팡에서 매출은 나는데(검색 상위) 상세페이지가 아쉬운 상품 찾기 — 판매자 정보의 이메일 직접 확인
  2. 아래 기본형 메일 + 우리 상세페이지 전체 이미지(본문에 바로 보이게)
  3. 회신 오면 → 그 상품으로 앞 2~3장 무료 시안
  4. 마음에 들면 → 찰칵상세로 전체 제작 (가격은 이때)

제재 안 받는 규칙

  • 제목 맨 앞 (광고) · 본문 끝 연락처 + 수신 거부 방법
  • 하루 3~5곳, 한 곳씩 맞춤 문장 (대량 발송 X, 주소 자동 수집 X)
  • 오전 9시~오후 6시에만 · 수신 거부한 곳은 다시 보내지 않기
  • 리브 드 보떼 이름·링크는 노출하지 않고 이미지로만
  • 보내기 전 항상 민성님 확인
